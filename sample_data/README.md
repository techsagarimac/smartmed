# Sample data

The API seeds a demo user when the database is empty and `SMARTMED_SEED=true`.

Printed-label photos for a viva:

1. Photograph a real OTC package you already have, or print a label that contains only a name and strength you saved in SmartMed, for example `PARACETAMOL 500 mg`.
2. Save the photo and use **Scan & verify** → upload.
3. For mismatch, scan a different pack than the saved medicine.

Do not photograph other people’s prescriptions. SmartMed is not a drug identifier for unknown tablets.
